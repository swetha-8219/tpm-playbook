# The TPM Playbook

**Program management templates that actually get used — launch checklists, risk logs, stakeholder updates, and decision records, built by a Technical Program Manager for anyone running cross-functional work.**

Most programs don't fail for lack of effort. They fail because nobody wrote down who owns what, what could go wrong, or what was decided and why. This repo fixes that with short, copy-ready templates.

## What's inside

| Template | Use it when |
| --- | --- |
| [Launch checklist](templates/launch-checklist.md) | You're shipping anything with more than one team involved |
| [RAID log](templates/raid-log.md) | You need risks, assumptions, issues, and dependencies in one place |
| [Stakeholder update](templates/stakeholder-update.md) | It's Friday and leadership needs a one-page status |
| [Program review](templates/program-review.md) | You're running a monthly or quarterly program review |
| [Decision log (ADR)](docs/decision-log.md) | A decision was made and you never want to re-argue it |

## How to use a template

1. Copy the template file into your own doc, sheet, or wiki.
2. Replace the bracketed placeholders (`[like this]`) with your program's details.
3. Delete the sections that don't apply. A short, honest doc beats a long, ignored one.

## Principles

- **One page beats ten.** If a status update needs a second page, it's a meeting, not an update.
- **Owners, not teams.** Every action item names one person and one date.
- **Write the decision down.** If it isn't logged, it will be debated again next quarter.
- **Risks are not pessimism.** A risk log is how a program stays boring — in a good way.
